# Security review: keys, localhost server, inputs (2026-11-03)

Independent reviewer agent; read the code, proved findings with offline tests (`tests/security/findings.test.ts`, now flipped into regression tests). All fixes landed in the commit that adds this file.

| # | Sev | Finding | Fix |
|---|---|---|---|
| H1 | high | The `llm` engine id flowed into a file path (`analysis-${llm}.json`): `"/../../../secrets/keys"` read the key file back over HTTP and could write `.json` anywhere | `EngineSpec` (fixed set of engine ids + optional model slug, no `..`) in `RenderSettings` and the ideas route; cache file names are a SHA-256 of the id; voice/size/fps/pin/drop bounded |
| M1 | med | SSRF guard missed IPv4-mapped IPv6 in hex form (`[::ffff:7f00:1]`), most of fe80::/10, NAT64, CGNAT, 198.18/15 | `net.BlockList` with full private/reserved ranges; mapped addresses unwrapped (dotted and hex) |
| M2 | med | Redirect hops and DNS rebinding were checked after the request | manual redirects (every hop checked first, ≤ 6), an undici dispatcher that re-checks the resolved address at **connect** time, 90 s timeout; ingest has a 120 s timeout |
| M3 | med | The OAuth callback (a cross-site top-level redirect) was blocked by our own cross-site guard, so "link your account" couldn't work | exempt exactly `GET /oauth/openrouter/callback` with `Sec-Fetch-Mode: navigate` (the single-use state protects it); `start` is POST; pending states capped at 20 |
| M4 | med | Requests with no Origin and no fetch metadata (local tools) are trusted | **accepted** (ADR 0006): loopback-only, single-user; a same-user process can already read `~/.bridge`. Mitigated with an owner-only `~/.bridge` (L6). Real auth is a precondition for any non-loopback exposure |
| M5 | med | Upload/JSON size limits applied after buffering (chunked bodies) | `hono/body-limit` while streaming: 81 MB for uploads, 256 KB for other API bodies → 413 |
| M6 | med | `redactDeep` regex-edited serialised JSON and could corrupt it → 500 / crash in `JobQueue.save` | redact leaf strings only |
| L1 | low | Static/asset path checks were prefix comparisons (`dist-private` sibling), bad `%` encodings threw | compare against `root + sep`; decoding errors → 400 |
| L2 | low | Uncaught errors went to stderr unredacted | `app.onError` redacts and returns a generic 500 |
| L3 | low | `Range: bytes=-10` served the first bytes | suffix ranges served correctly |
| L4 | low | Huge images / PDF MediaBoxes could exhaust memory | header-only image size check (> 50 MP refused); PDF render scale clamped to ≤ 6000 px |
| L5 | low | Narration passed as argv to `say`/`espeak` (a line starting with `-` is a flag) | text goes through `-f in.txt` |
| L6 | low | `~/.bridge` was world-readable | created/chmodded 0700 at server start |
| L7 | low | Redaction missed ElevenLabs `sk_…` keys and JSON-style headers; `sk-` matched inside words; removed keys were un-registered | patterns fixed with word boundaries; removed keys stay registered |
| L8 | low | Keychain probe could never fail (Linux without Secret Service never fell back) | probe the raw keyring API |
| L9 | info | Error message suggested a `bridge keys` command that didn't exist | added `bridge keys list/set/remove` |

Verified solid by the reviewer: loopback bind + bind guard, exact Host allowlist (uppercase, trailing dot, `[::1]`, missing host all refused), `Origin: null` refused, cross-site refused for every method, no CORS, strict CSP/XFO/CORP; `providerFetch` (https, host-pinned, no redirects, header set last, redacted errors); PKCE (48-byte verifier, S256, 144-bit single-use state, TTL, escaped callback HTML); 0600/0700 key file with atomic rename; masked-only API; fflate zip limits (no zip-slip, nothing extracted to disk); pdfjs 4.10.38 with `isEvalSupported:false` (CVE-2024-4367 fixed); id regex everywhere; no `innerHTML`; `.gitignore` covers secrets.
